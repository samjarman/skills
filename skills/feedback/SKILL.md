# Feedback

The user is correcting something you just did. Read the feedback supplied with this invocation and the conversation around it. Find the relevant agent instructions, such as `AGENTS.md`, and make a concise, specific update that captures the lesson. Keep it scoped to the project or preference the feedback applies to; don't turn a local correction into a universal rule. Update existing guidance where possible rather than adding duplicate or conflicting instructions. Tell the user what you changed.

Example: `/feedback you just checked Jira when we use GitLab issues instead`
