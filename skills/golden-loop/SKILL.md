# Golden loop

The user supplies two things: what they want to achieve and a deterministic check that proves it's working. If either is missing or unclear, ask for it before starting. Once both are clear, work autonomously: make progress, run the check, use failures to guide the next change, and repeat until it succeeds. Don't weaken or change the agreed check to make it pass. When it succeeds, tell the user you're done and include the result. If you hit a guardrail or blocker you cannot resolve within your existing permissions, report it rather than claiming completion.
